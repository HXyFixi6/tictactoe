# Tic-Tac-Toe

Ce projet est une implémentation du jeu Tic-Tac-Toe, développé avec **React** et **Vite**. 

---

## Installation et Exécution

Pour exécuter ce projet localement, assurez-vous d'avoir [Node.js](https://nodejs.org/) installé sur votre machine (v22, je n'ai pas testé avec une version inférieure).


### Installation
à la racine du projet exécuté : 

```bash
npm install
```


### Exécution

à la racine du projet exécuté : 
```bash
npm run dev
```

Le terminal affichera une adresse locale (généralement http://localhost:5173/). Cliquez sur le lien pour tester l'application.
